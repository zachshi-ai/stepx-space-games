# STEPX Neo 空间交互小游戏

三款只用手机构造姿态操作的竖屏小游戏，各自独立安装包。

| 安装包 | 应用名 | 包名 | 玩法 |
|---|---|---|---|
| `sand.apk` | 重力沙盘 | com.stepx.sand | 倾斜手机晃动小球入环，翻面反转重力 |
| `beacon.apk` | 灯塔号 | com.stepx.beacon | 转身把信号点转到正上方，五座灯塔 |
| `room.apk` | 无接触密室 | com.stepx.room | 五道姿态口令：扣屏、举天、转圈、定身、翻面 |

系统要求：Android 7.0（API 24）及以上。竖屏全屏，无需联网，传感器不可用时可切触屏兜底。
