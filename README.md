# STEPX Neo 空间交互小游戏

三款只用手机构造姿态操作的竖屏小游戏，各自独立安装包。

## 安装包（v1.0.2）

| 文件 | 应用名 | 包名 | 体积 |
|---|---|---|---|
| `apk/sand.apk` | 重力沙盘 | com.stepx.sand | 189 KB |
| `apk/beacon.apk` | 灯塔号 | com.stepx.beacon | 225 KB |
| `apk/room.apk` | 无接触密室 | com.stepx.room | 185 KB |

## 玩法

- **重力沙盘**：手机就是托盘。倾斜晃动青球进入绿色刻度环，把屏幕翻过来时重力反向，球会贴到"天花板"上。三关，黑洞有真实引力场。
- **灯塔号**：手机是一座罗盘。原地转身把信号点转到正上方并稳住 1.2 秒，共五座灯塔。
- **无接触密室**：五道姿态口令——扣屏、举天、原地转整圈、定身、翻面三连，全程不用碰屏幕。

## 系统要求

Android 7.0（API 24）及以上。竖屏全屏、屏幕常亮、无需联网。传感器不可用或被拒绝时自动切触屏兜底。

## 技术说明

原生 WebView 外壳，页面内嵌于 assets，Tailwind 已内联，完全离线。页面通过自建的 `https://game.local/` 虚拟域加载，保证处于安全上下文，`deviceorientation` 不会被浏览器策略拦截。
